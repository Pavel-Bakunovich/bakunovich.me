# Pavel Bakunovich's personal web site.

## Markdown pages

Add a Markdown file to `pages/` to publish it at a matching URL. For example,
`pages/wishlist.md` is available at `/wishlist`. Files in `pages/` must be
top-level `.md` files; their names become the URL path (use hyphens for
multi-word paths, such as `reading-list.md` for `/reading-list`).
